# 天數計算器

從指定起始日期計算已過天數，設定目標天數並在互動月曆上標記。

## 功能

- 選擇起始日期，即時顯示已過天數
- 新增多個目標天數，顯示對應到達日期
- 月曆可切換年月，目標日期以彩色圓點標記
- Hover 月曆日期顯示日期與天數
- 支援 URL query 帶入參數
- localStorage 自動儲存設定

## 使用方式

直接開啟 `index.html` 即可使用。

### URL 參數

```
index.html?start=2026-01-01&targets=100,200,365
```

| 參數 | 說明 | 範例 |
|------|------|------|
| `start` | 起始日期（YYYY-MM-DD） | `2026-01-01` |
| `targets` | 目標天數，逗號分隔 | `100,200,365` |

## 技術

純 HTML + CSS + JavaScript，無框架依賴。
